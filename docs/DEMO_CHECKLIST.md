# Demo checklist

- [ ] Sign in with a test business account.
- [ ] Confirm the active organization.
- [ ] Upload a clearly labelled sample payment CSV.
- [ ] Show validation and imported row count.
- [ ] Show one detected anomaly with sample size and baseline evidence.
- [ ] Explain possible causes as hypotheses.
- [ ] Show a recommended action.
- [ ] Approve or reject and show action history.
- [ ] Show workflow module only if its data path is working.
- [ ] Do not use real customer data without authorization.
